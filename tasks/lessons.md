# Solaris Engineering Lessons & Decisions

## Architectural Decisions
- **Native Rust Agent Runtime over Mastra/Node**: Keeping OpenRouter orchestration in Rust (`tokio` + `reqwest`) eliminates a Node.js sidecar, saves ~150–250 MB RAM, and enables direct in-process `ProjectEngine` mutations.
- **Transport Boundary (`EngineClient` over HTTP/WS)**: Never coupling UI components to Tauri `invoke()` keeps ~95% of the codebase identical between the local-first Desktop app and future Web SaaS deployment.
- **Dual-Path Rendering**: Native FFmpeg handles A-Roll/B-Roll/Color/Audio at full native speed; headless Chromium is used strictly for custom HTML/GSAP overlay frames.

## Technical Gotchas
- **Axum 0.8 Route Syntax**: Axum 0.8 requires `{param}` instead of `:param` (using `:id` panics at runtime).
- **Rust Edition 2024**: `std::env::set_var` is `unsafe` in edition 2024—avoid mutating process env in tests; inject config structs directly.
- **TypeScript Monorepo Typechecking**: `@solaris/engine-client` must emit `.d.ts` declarations (`npm run build --workspace=@solaris/engine-client`) before `@solaris/studio-web` runs `tsc -b --noEmit`.
- **Vite `import.meta.env`**: Include `src/vite-env.d.ts` (`/// <reference types="vite/client" />`) in `apps/studio-web`.
- **FFmpeg Path & Shared Dylibs**: `media-engine` degrades gracefully when `ffmpeg`/`ffprobe` are absent on `PATH`; if pointing to a dynamically linked FFmpeg build, `DYLD_LIBRARY_PATH` must include its `.dylib` directory.
- **Tauri Workspace Isolation**: Keep `apps/desktop/src-tauri` in `[workspace] exclude` so headless server/CI builds stay free of desktop WebKit/AppKit dependencies, and verify it separately via `cargo check --manifest-path apps/desktop/src-tauri/Cargo.toml`.
- **WebGL2 Pixel Sampling**: Always set `crossOrigin="anonymous"` on `<video>`/`<img>` feeding `texImage2D`, keep `<canvas>` persistently mounted, and initialize WebGL2 with `{ preserveDrawingBuffer: true }` so `BroadcastScopes` can read back downsampled graded pixels via imperative refs without triggering React re-renders.
- **WKWebView Bearer Auth Boundary**: `<video>`, `<img>`, and `WebSocket` cannot attach custom `Authorization: Bearer` headers. Exchange the Bearer token once at startup via `POST /api/v1/auth/session` for an `HttpOnly` cookie + ephemeral read-only `media_ticket` (passed via `?ticket=` for media streams and `Sec-WebSocket-Protocol` for WebSockets).
- **FFmpeg Input Stream Indexing**: Track `input_count` separately from `inputs.len()` (which counts CLI flag strings like `-loop`, `1`, `-i`, `path`) so `-filter_complex` stream indices `[k:v]`/`[k:a]` always match FFmpeg's 0-based input indices.
- **Constant-Memory HTTP Range Streaming**: `206 Partial Content` responses must stream via `ReaderStream::new(file.take(len))` with `Content-Length: len`, never `file.read_exact(&mut vec![0u8; len])`.
- **Undo Stack Isolation for Background Metadata**: Derived background jobs (`UpdateMediaIntelligence`, proxy generation) must never push onto `undo_stack` or clear `redo_stack`.
- **Audio Analysis Without Video Decoding**: Always pass `-vn` to FFmpeg `silencedetect`, `ebur128`, and PCM peak extraction passes, and combine `silencedetect` + `ebur128` into one pass.
- **OpenRouter Tool Naming & Fallback Arrays**: OpenAI/Anthropic endpoints via OpenRouter reject dots in function names; send underscore names (`timeline_place_clip`) to OpenRouter and dot names (`timeline.place_clip`) in MCP `tools/list`, normalizing both in `execute_tool`. When sending model fallbacks, pass `models: [primary, ...fallbacks]` with `model: None`.
- **Byte-Buffered SSE UTF-8 Framing**: Always buffer raw `Vec<u8>` up to `b'\n'` before UTF-8 decoding SSE streams so multi-byte characters split across HTTP chunks are never corrupted.
- **Sequential Swarm Status Channel**: Never spawn detached `RwLock::write` tasks from an async `on_status` callback; route updates through an `mpsc` channel drained by a single sequential writer so intermediate states can never overwrite `Completed`/`Failed`.
- **Single-Parity MCP `stdio` Bridge**: Forwarding `solaris-mcp` `stdio` JSON-RPC directly to `solaris-server`'s `/mcp` Streamable HTTP endpoint guarantees 100% tool parity (`preview.capture_frame`, `preview.seek`, live `McpExternal` cursors) without duplicating REST client logic.
- **Sync `AssetStorage` in Async Contexts**: Because `AssetStorage` is a synchronous trait called from both sync tests and Tokio async handlers, `S3Storage` runs `reqwest` HTTP calls on a dedicated `std::thread::spawn` with a `current_thread` Tokio runtime rather than `block_in_place` (which panics on `#[tokio::test]` single-threaded runtimes).
- **Zero-Extra-Crate SigV4 Signing**: Reusing `ring` (`digest::SHA256`, `hmac::HMAC_SHA256`) already in `Cargo.lock` keeps `S3Storage` lightweight and audit-friendly without pulling in heavy cloud SDK dependency trees.
- **Non-Loopback Host File Read Guard**: `allow_external_media_reads` must default to `false` whenever `solaris-server` binds outside loopback so authenticated web/Docker clients cannot import arbitrary container paths.
- **FFmpeg Overlay & Alpha Export Safety**: Single-image PNG overlays require `eof_action=repeat` (or `-loop 1` + `shortest=1`) so overlays don't vanish after frame 1; alpha exports (`MovProRes4444`/`WebmAlpha`) require `:format=auto` on `overlay`, `format=rgba` before transparent padding, and preserving alpha around color grading; always drain `child.stderr` concurrently on a background thread to prevent OS pipe deadlocks.
- **Chromium `file:///` & Sandboxed GFX CSP**: Canonicalize relative HTML paths and percent-encode segments before launching headless Chromium; inject `Content-Security-Policy: default-src 'none'; style-src 'unsafe-inline'; script-src 'unsafe-inline'; img-src data:; font-src data:;` alongside bundled GSAP + base64 `@font-face` rules so offline/sandboxed motion graphics render deterministically without CDN access.
- **FFmpeg 8 `af_whisper` NDJSON Format**: FFmpeg 8's `whisper` audio filter emits newline-delimited JSONL (`start`/`end` in milliseconds) rather than a single OpenAI JSON object; always parse both formats and preserve short zero-duration words (`start == end`) with a minimal `0.05s` duration.
- **OpenRouter Model Discovery & Streaming Resilience**: Query OpenRouter `/models` with `output_modalities=all` so audio/STT models aren't filtered out; guard JSON `null` values in model metadata with `deserialize_null_default`; check for HTTP `200 OK` JSON `{"error": ...}` bodies during SSE streaming; use `connect_timeout` + `read_timeout` (not total request timeout) and cap/validate tool-call JSON arguments before dispatching tools.
- **WebGL2 3D LUT Half-Texel Addressing**: Sample 3D LUT textures using `(rgb * (u_lutSize - 1.0) + 0.5) / u_lutSize` so `0.0` and `1.0` land on exact texel centers without edge bleeding, and trigger an immediate redraw once the `.cube` LUT texture finishes uploading.
- **Monotonic UI State & WS Event Ordering**: Emit WebSocket `OpCommitted`/`ProjectReset` while holding the project write lock so revision order is strictly monotonic on the wire; guard React `activeProject`, `exportJob`, and `swarmRun` updates against stale HTTP `202` or out-of-order responses; never store API keys or auth tokens in `localStorage` (use OS Keychain via Tauri + authenticated `/api/v1/agent/credentials` / `HttpOnly` session cookies).
- **Tauri Startup Race & Native Export Downloads**: Declare `"create": false` on the main window in `tauri.conf.json`, bind and `app.manage(...)` the embedded `solaris-server` *before* calling `WebviewWindowBuilder::from_config`, trigger graceful shutdown on `RunEvent::Exit`, and provide a confined native `save_export_file` bridge for macOS WKWebView downloads.
- **Persistent CDP Chromium Rendering**: Reusing a single headless Chromium process via local Chrome DevTools Protocol (`Page.navigate` + `Runtime.evaluate` + `Page.captureScreenshot`) eliminates per-frame cold startup overhead on animated GFX/caption sequences while keeping strict offline network isolation and RAII `ChildGuard` process reaping.
- **Unquoted 2-Level FFmpeg Filter Path Escaping & FFmpeg 8/9 `-filter_complex`**: Passing unquoted 2-level escaped paths to `lut3d=file=...` and `whisper=model=...` avoids quote-nesting bugs on paths containing apostrophes, colons, or backslashes. In FFmpeg 8+/9+, `-filter_complex_script` was removed in favor of `-/filter_complex <file>`; pass `-filter_complex` inline for standard graphs (`<= 24 KiB`) and use `-/filter_complex` with fallback to `-filter_complex_script` for oversized graphs so exports work seamlessly across FFmpeg 5–9.
- **Graceful WebSocket Shutdown Token**: `axum::serve(...).with_graceful_shutdown(...)` waits for active upgraded WebSocket connections to finish before exiting; cancel a shared `CancellationToken` in `AppStateInner` during `SIGTERM`/`SIGINT` and Tauri `RunEvent::Exit` so `handle_ws`'s `tokio::select!` immediately sends a Close frame and terminates cleanly (with a 3s timeout + task abort safety net in desktop mode).
- **Tauri CSP & Sandboxed GFX Endpoint**: Keeping `script-src 'self'` on the main document while serving untrusted LLM-authored GFX HTML from `/api/v1/gfx/sandbox/{id}` (authorized via `?ticket=`/cookie, `frame-src 'self' http://127.0.0.1:* data: blob:`, and response `Content-Security-Policy: ...; sandbox allow-scripts`) isolates GFX execution in a unique opaque origin without weakening main-window CSP.
- **WebGL2 Ref Stabilization & Non-Blocking Disk Persistence**: Keep imperative WebGL2/audio/RAF callbacks reading from stable refs instead of recreating render loops on React state churn, and serialize brand/asset JSON writes behind dedicated `tokio::sync::Mutex<()>` persist locks so global `RwLock` maps are never held across disk `fsync`.
- **Distortion-Free Program Stage & Zero-Overflow 1.0× Timeline**: Combining CSS `height: 100%` + `maxWidth: 100%` + `aspectRatio` distorts 16:9 canvases in narrow columns; compute exact fitted pixel dimensions via `ResizeObserver` on the stage well so WebGL2, GFX iframes, and captions stay 100% aspect-true across 16:9, 9:16, and 1:1. Similarly, apply `minWidth: "${zoom * 100}%"` on timeline lanes only when `zoom > 1` (with `min-w-0 flex-1` at 1.0×) so the `w-40` sticky track header never forces a permanent 160px horizontal scrollbar.
- **Progressive-Disclosure Skill Packaging & GFX Positioning Tools**: Keeping `SKILL.md` lean (~115–180 lines) while placing deep tool tables, GFX GSAP contracts, and QA rubrics in 1-level-deep `references/*.md` keeps internal OpenRouter swarm prompts token-efficient while giving external MCP agents (`solaris-mcp install-skills` and `skill://<name>/references/<file>.md`) full operational mastery. Also ensure `AgentRole::Gfx` and `AgentRole::Caps` retain `timeline.set_transform` in `tools_for_role` because `gfx.place` always initializes at `(0, 0)` and needs a follow-up transform to stay clear of `T1` captions.
- **Hidden (not unmounted) Program Stage**: When the viewer switches to the Source tab, keep `WebGLProgramStage` mounted with `display: none` so the WebGL2 context, GFX iframes, and scope pixel feed survive; its `ResizeObserver` re-measures automatically when shown again. Mount `SourceMonitor` with `key={media.id}` so IN/OUT markers reset per clip without an effect.
- **OpenRouter Reasoning Token Budgets & Truncated JSON**: Reasoning-capable models on OpenRouter count internal `reasoning_tokens` against `max_tokens`; small caps (`1200–1400`) cause mid-string JSON EOF truncation (`finish_reason: "length"`). Always capture `usage` + `completion_tokens_details.reasoning_tokens` + `finish_reason`, allocate generous output budgets (`4096`/`8192` for Director/Workers), make `DirectorPlan` fields `#[serde(default)]`, retry once on truncation/parse failure, and stream full diagnostic context (with secret redaction) to the bounded `/api/v1/logs` ring buffer + `EngineEvent::LogEmitted`.
- **Zero-Asset Programmatic Video Pipeline**: When `media_pool` contains zero video/image assets, skip empty `V1`/`V2`/`FX` footage workers and let `Gfx` + `Caps` build the entire timeline programmatically (full-canvas responsive HTML/CSS/SVG/GSAP scenes covering `0.0s..target_duration_sec` on `G1` + `captions.place_script` kinetic captions on `T1`), support overlay-only `capture_preview_frame` for Vision QA, and hide the Program Stage empty-state placeholder whenever `G1`/`T1` clips are active.
- **Dark-Mode Iframe `color-scheme` Transparency & Canonical Virtual GFX Stage**: Per the HTML/CSS Color Adjustment spec, embedding a default `light`-scheme `<iframe>` inside a `color-scheme: dark` parent forces Chromium/WebKit to paint an opaque white canvas behind the iframe even when `background: transparent !important` is set. Always emit `<meta name="color-scheme" content="dark" />` + `color-scheme: dark` inside `buildSandboxedGfxDoc` / `build_overlay_html` and `colorScheme: "dark"` on `SandboxedGfxFrame`. In `WebGLProgramStage`, render GFX iframes inside a canonical virtual viewport (`540×960` / `960×540` / `720×720`) scaled to the fitted monitor via CSS `transform: scale(...)` so overlays never clip or wrap awkwardly on narrow 9:16 panes.
- **Interactive Model Filtering, Per-Turn GFX Cadence & Honest Visual QA**: Exclude OpenRouter `:batch` variants from interactive Director/Specialist scoring in `ModelAdvisor` (their discounted pricing otherwise outranks reliable streaming models). Instruct `gfx-01` to emit only 1–2 compact scenes per turn via `gfx_place` directly (skipping redundant `gfx_lint_html` pre-calls) with automatic model-rotation truncation recovery and a Director-model recovery pass if `g1` stays empty. In QA, treat empty `V1`+`V2`+`G1` (`visuals-empty`), low programmatic `G1` coverage, specialist failures, and Vision QA `issues` as hard `QaSeverity::Issue` failures (never letting a blank black frame pass at `85/100`), and never vertically offset full-canvas (`100vw`/`100vh`/`inset:0`) `G1` backgrounds during caption anti-collision.
- **`@fontsource-variable/sora` Font Family Name & Caption Parity**: `@fontsource-variable/sora` registers `'Sora Variable'` (not `'Sora'`). Passing bare `fontFamily: "Sora"` on `CaptionOverlay` fell back to the browser's default serif font; always normalize `"Sora"` to `'"Sora Variable", "Sora", -apple-system, BlinkMacSystemFont, sans-serif'`, keep `WebGLProgramStage.tsx` and `gfx_render.rs` on the same `50% + y * 78%` vertical mapping, and preserve segment/clause boundaries with balanced chunking (`2+2` instead of `3+1`) in `captions.place_script`.
- **Parallel Scene Micro-Agent Fan-Out, Gated Low-Reasoning & Batched Cursor Events**: Sending `reasoning: { effort: "low" }` with `require_parameters: true` causes 404s on OpenRouter endpoints that don't advertise `"reasoning"`—always gate `ReasoningConfig` on `advisor.model_supports_parameter(model, "reasoning")` and relax `require_parameters` when attached. For programmatic `G1` videos, fanning out 1 micro-agent per scene via `tokio::task::JoinSet` (sharing a unified Director `art_direction` brief, a shared `"gfx-swarm"` track lock on `g1`, and per-run unique `clip_id` suffixes) cuts latency ~5× while raising scene quality. On the frontend, never track a capped sliding-window `events` array by `.length` (which permanently stalls once the buffer saturates) and never append `log_emitted` into `events`; track the last processed envelope by object reference (`lastProcessedEventRef`), separate `lastRealEventAt` from scanning drift ticks so idle cursors expire cleanly, and map `timeline.track.<id>@<sec>` anchors using `TimelinePanel`'s exact `timelineSpan`.
- **Chromium `deviceScaleFactor` GFX Coordinate Parity & Honest QA Scoring**: Because built-in GFX templates and Studio Preview (`WebGLProgramStage.tsx`) author overlays in a canonical virtual viewport (`540×960` / `960×540` / `720×720`), headless Chromium (`gfx_render.rs`) must render `G1` clips at the same CSS viewport with `deviceScaleFactor = canvas_w / design_w` (`2.0x` for 1080p, `1.5x` for 1080×1080) so Studio preview, Vision QA, and exported MP4/MOV/WebM match 1:1 at full crisp physical resolution. In QA (`qa/checks.rs` + `qa/mod.rs`), never `break` early out of coverage accumulation loops, cap failing reports (`issue_count > 0`) to `<= 65` so numeric scores never contradict `passed: false`, and strip both `"` and `'` in `sanitize_css_val` to prevent HTML attribute breakout.
- **Chromium CDP HTTP Keep-Alive & Programmatic QA Safe-Band Alignment**: Chrome's local DevTools HTTP server (`/json/list`, `/json/new`) sends `Content-Length` and ignores `Connection: close`, keeping the TCP socket open; calling `TcpStream::read_to_end` always stalls until read timeout and silently degrades every render/QA call to hundreds of cold CLI Chrome spawns. Always parse HTTP headers and read exact `Content-Length` (or chunked) bytes. For programmatic `9:16` videos, `T1` captions at `y = 0.24–0.25` occupy `~64%–75%` height, so `G1` foreground content must stay in `5vh..61vh` (with ambient backdrop continuing full `100vh`) and Vision QA must sample settled mid-scene timestamps (`~50%` into hook/mid/outro scenes) while knowing `video_clips == 0` is intentional in zero-asset mode.
- **Swarm Cursor Liveness & Lock-Alias Filtering**: Never advance `lastProcessedEventRef` in `SwarmCursorLayer` while `enabled` is `false`, or initial `cursor_pulse` events arriving alongside `swarm_progress` are silently dropped before auto-enable commits. Filter shared internal lock IDs (`"gfx-swarm"`) from `op_committed` cursor updates when parallel micro-agents (`gfx-01..07`) emit individual `cursor_pulse` events, always resolve `timeline.track.*` anchors to `[data-timeline-lane]`, and apply subtle work micro-jitter on streaming pulses so repeated pulses on the same `@sec` slot stay visibly alive instead of resetting the drift timer at a fixed pixel.
- **Relative `workspace_dir` Path Doubling on Export/Media Storage**: `ServerConfig::default().workspace_dir` is relative (`.solaris-data`). Leaving `AppStateInner.workspace_dir` un-canonicalized while `LocalFsStorage` canonicalized its `workspace_root` caused `state.inner.workspace_dir.join("exports/...")` + `sync_file` to emit `.solaris-data/exports/...`, which `resolve_readable_path` then joined onto `/abs/.solaris-data` (`.../.solaris-data/.solaris-data/exports/...` `ENOENT`). Always canonicalize `workspace_dir` in `AppState::initialize`, canonicalize `LocalFsStorage::sync_file`, and test with a relative `workspace_dir` (not only `std::env::temp_dir()`).
- **Retired Tools Must Leave Prompts, Skills & Deterministic Paths**: Role allowlists (`tools_for_role` + `validate_worker_tool_scope`) only gate LLM tool calls. Deterministic fallbacks call `execute_tool` directly, and prompts/`skills/` keep naming the tool, so a tool removed from a role still produced captions and tool-call rejections. When retiring a tool for a role, purge it from the role brief, `skills/**/references`, `docs/`, and fallback code in the same change, and pin the behavior with a test (zero-asset plans must emit no captions without narration).
- **Pre-Render Folder Permission & Fast-Export Delivery Race**: In browsers supporting File System Access (`window.showDirectoryPicker`), acquire or verify `readwrite` folder permission during the user's "Render" click so automatic streaming (`res.body.pipeTo(writable)`) succeeds after a long render without needing a second gesture; bump a `deliveryArmSeq` state counter alongside `armedDeliveryRef` so fast renders whose WS `completed` event arrives before HTTP `202` resolves still trigger automatic saving.
- **Batches Fail Whole on a Locked Track**: The engine rejects a `Batch` if any sub-command targets a track with the IR `locked` flag, so the selection builders (`lib/timelineSelection.ts`) skip locked clips and report the count (`lockedClipCount`) for the toast. `TrimClip` rejects negative starts, so a group move clamps one shared delta (`clampGroupDelta`) instead of clamping each clip, which keeps the spacing between clips.
- **Round Emitted Times to Milliseconds**: Float subtraction produces values like `0.39999…`. Round every emitted start, split time, and delta to 1 ms before serializing, so the JSON is exact and no-op checks compare equal.
- **`SplitClip` Takes the Right Half's Id**: The engine assigns the caller's `right_clip_id` to the new clip (`right.id = right_clip_id`, `engine.rs`) rather than generating one. The command replays identically on redo, and the UI knows which clip to select afterwards. Batch split generates one safe id per clip (1 to 64 ASCII `[A-Za-z0-9_-]`).
- **Track Locks Versus User Commands**: The IR `locked` flag blocks every actor, and only a user `SetTrackFlags` can unlock it. Agent-held `track_locks` block other agents, but `AgentRole::User` commands pass through them, as the other user actions already do. A GFX placed from the bin now uses the user actor (`agent_id: "user"`), so it shows no AI cursor, and it can land while a swarm holds the G1 lock.
- **Helper Modules Use Type-Only Imports**: `node --test` runs `src/lib/*.ts` through type stripping, so these helpers use `import type` only, with no enums, namespaces, or parameter properties. Storage is injected (`DirectorHistoryStorage`), so the tests need no browser.
- **Duplicate GFX Ids Come From a Fresh List**: `save_asset` upserts, so a duplicate must pick an id that is free in a fresh `listAssets()` result. Server ids are at most 64 safe characters (`<id>-copy`, `<id>-copy-2`, and so on).
- **Restore Focus Only After Keyboard Activation**: After a GFX card action, return focus to the card only when the action was keyboard-triggered (`event.detail === 0`). Otherwise focus stays on a card button, and Space adds a GFX by accident.
- **Shortcut Guards Miss Focusable Containers**: The global shortcut guard covers `INPUT`, `TEXTAREA`, `SELECT`, `BUTTON`, `A`, and sliders. Focusable containers with `tabIndex=-1`, such as the GFX list, are not covered, so check the focus target explicitly.
- **Direct Download Links Keep the Server Name**: A `<a href>` to `/api/v1/exports/{id}/download` cannot keep the chosen file name, because the server's `Content-Disposition` filename overrides the anchor's `download` attribute. Cross-origin links also ignore `download`, and a navigation cannot report errors in-app. The browser fallback therefore keeps the Blob path and documents its memory limit. Revisit it only if the server adds a filename override and a probe that doesn't stream the body.
- **Debounce Timers Live in Refs**: `useGfxAssetSync` keeps its 150 ms refetch timer in a ref. Clearing the timer in an effect cleanup would drop a pending refetch whenever the effect re-runs.
- **Narration Gating & Sound-Tag Stripping**: `swarm/speech.rs::narrated_transcript_present` strips bracketed/parenthesized/asterisked tags (`[Music]`, `(applause)`, `*sigh*`) and musical symbols (`♪`, `♫`, `♬`, `♩`) and requires at least 3 alphanumeric words on a `V1`/`A1` clip or voice-hinted audio asset before any caption producer runs.
- **Refinement Plan Validation & Safe Dispatch**: `parse_refinement_plan` normalizes role names through `AgentRole`, drops unknown/disallowed roles, deduplicates, caps at 4 roles, and treats empty targets as a zero-op `Completed` run; refine mode never falls back to deterministic generation when no OpenRouter key is configured.
- **Dismissal-Before-Delete & Corrupt-File Quarantine**: `AppState::delete_asset` persists `.dismissed_starters.json` *before* removing `assets/{id}.json` (rolling back dismissal if removal fails) so a failed write can never resurrect a deleted starter on restart; corrupt `.dismissed_starters.json` is quarantined to `.dismissed_starters.corrupt-<unix>.json` with a `push_log` warning.
- **Non-Secret Per-Project History & GFX Drag MIME Contract**: Director refinement history stores only `{ role, text }` (never API keys or tokens) in `sessionStorage` under `solaris:director-history:<projectId>` (capped at 20 stored / 12 sent), and `lib/dragPayloads.ts` (`GFX_ASSET_DRAG_MIME = "application/x-solaris-gfx-asset"`) is the shared contract between `GfxAssetCard` and `TimelinePanel`'s `G1` drop lane.
- **Anti-Slide-Chrome & Closed-Loop Vision QA Auto-Repair**: Never hardcode scene counters (`01 / N · TAG`) or bottom progress rails in `swarm/llm.rs` or `skills/`—they force every programmatic video into a repetitive dashboard slide deck. Keep Vision QA (`qa/vision.rs`) sampling all `G1` scenes (up to 7) with `clip_id` attribution, and wire `auto_fix: true` / `Enhance` (`qa/repair.rs`) to patch failing `G1` HTML in place (linted + single-undo atomic `Batch`) followed by a verification pass so Enhance actually resolves visual defects instead of re-reporting them. Also parse PT-BR/ES duration tokens (`segundos`, `seg`, `minutos`) in `infer_target_duration_from_prompt`.
- **Lean Scene-Worker Prompts, SVG Anti-Collision & UI Canvas Authority**: Omit the 21 KB `move-playbook.md` catalog from `run_programmatic_scene_worker` (keeping `gfx-contract.md` + `motion-craft.md`) so per-scene prompts drop from ~17K to ~10K tokens and low-reasoning workers retain focus on geometry. Enforce a 3-zone CSS Grid (`grid-template-rows: auto 1fr auto`), HTML Flex/Grid for multi-word labels (never hand-placed SVG `<text>` over dense node graphs or empty hollow rings), explicit `svgOrigin: "<cx> <cy>"` on SVG rotations (checked by both Rust & TS GFX linters so globes never orbit off-center), cross-scene `header_alignment` locking in Director `art_direction`, `>= 13px` / `>= 0.70` contrast floor for disclaimers, continuous mid-scene GSAP motion (`stroke-dashoffset` edge pulses) on clips `> 3.0s`, UI-selected `project.canvas` aspect authority over prompt text, `BrandPlaybook.lock_brand_palette` toggle for explicit Brand-vs-Prompt color precedence, `MAX_REPAIR_CLIPS_PER_PASS = 7` with `medium` reasoning in `qa/repair.rs`, and filter the advisory `missing-brand-tokens` hint out of `InspectorPanel.tsx` on bespoke inline scenes.
- **Descendant SVG CSS Bleed, Flow-Positioned Badges & 2-Round Visual QA Repair**: Writing `.funnel svg { position: absolute; inset: 0; width: 100%; height: 100%; }` instead of `.funnel > svg` (or an explicit class) captures nested icon `<svg>` elements inside child cards whenever GSAP applies `transform` (which turns each card into a containing block), stretching icons directly over card text. Both Rust (`lint.rs`) and TS (`packages/gfx-runtime/src/lint.ts`) linters use a brace-depth-aware CSS scanner (`@media`/`@supports`, `!important`, bare `svg`, backdrop sizing) and expose `descendant_svg_trap` / `descendant-svg-absolute`; `gfx.place`, `gfx.update_clip`, `check_gfx_lint`, and `qa/repair.rs` reject it immediately on Turn 1; `qa/repair.rs` uses `system_cached` with Round-2 escalation in the user payload; and `qa/mod.rs` runs up to 2 closed-loop repair passes re-capturing only modified clips per round.
- **Zero-Scrollbar 1.0x Timeline & Adaptive Track Density**: Unclamped rightmost ruler tick labels (`100%` with `-translate-x-1/2`) and `overflow-x-auto` at `1.0x` zoom cause a permanent bottom horizontal scrollbar on the timeline. Always use `overflow-x-hidden` at `zoom <= 1`, `solaris-scroll-no-x` with wheel pan/zoom + `Fit` reset when `zoom > 1`, and edge-clamp ruler tick labels (`computeRulerTicks` in `lib/timelineFormat.ts`). Defaulting `showAllTracks` to `true` with adaptive row heights (`44px` populated/active vs `26px` empty) keeps all 7 semantic channels visible and drop-ready without wasting vertical studio space. Also keep `StudioWorkspace.tsx` lean by extracting top chrome (`StudioHeader.tsx`) and footer telemetry (`StudioStatusBar.tsx`).
