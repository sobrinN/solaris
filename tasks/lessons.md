# Solaris Engineering Lessons & Decisions

## Architectural Decisions
- **Native Rust Agent Runtime over Mastra/Node**: Keeping OpenRouter orchestration in Rust (`tokio` + `reqwest`) eliminates a Node.js sidecar, saves ~150–250 MB RAM, and enables direct in-process `ProjectEngine` mutations.
- **Transport Boundary (`EngineClient` over HTTP/WS)**: Never coupling UI components to Tauri `invoke()` keeps ~95% of the codebase identical between the local-first Desktop app and future Web SaaS deployment.
- **Dual-Path Rendering**: Native FFmpeg handles A-Roll/B-Roll/Color/Audio at full native speed; headless Chromium is used strictly for custom HTML/GSAP overlay frames.

## Technical Gotchas
- **Axum 0.8 Route Syntax**: Axum 0.8 requires `{param}` instead of `:param` (using `:id` panics at runtime).
- **Rust Edition 2024**: `std::env::set_var` is `unsafe` in edition 2024—avoid mutating process env in tests; inject config structs directly.
- **TypeScript Monorepo Typechecking**: `@solaris/engine-client` must emit `.d.ts` declarations (`npm run build --workspace=@solaris/engine-client`) before `@solaris/studio-web` runs `tsc -b --noEmit`.
- **Vite `import.meta.env`**: Include `src/vite-env.d.ts` (`/// <reference types="vite/client" />`) in `apps/studio-web`.
- **FFmpeg Path & Shared Dylibs**: `media-engine` degrades gracefully when `ffmpeg`/`ffprobe` are absent on `PATH`; if pointing to a dynamically linked FFmpeg build, `DYLD_LIBRARY_PATH` must include its `.dylib` directory.
- **Tauri Workspace Isolation**: Keep `apps/desktop/src-tauri` in `[workspace] exclude` so headless server/CI builds stay free of desktop WebKit/AppKit dependencies, and verify it separately via `cargo check --manifest-path apps/desktop/src-tauri/Cargo.toml`.
- **WebGL2 Pixel Sampling**: Always set `crossOrigin="anonymous"` on `<video>`/`<img>` feeding `texImage2D`, keep `<canvas>` persistently mounted, and initialize WebGL2 with `{ preserveDrawingBuffer: true }` so `BroadcastScopes` can read back downsampled graded pixels via imperative refs without triggering React re-renders.
- **WKWebView Bearer Auth Boundary**: `<video>`, `<img>`, and `WebSocket` cannot attach custom `Authorization: Bearer` headers. Exchange the Bearer token once at startup via `POST /api/v1/auth/session` for an `HttpOnly` cookie + ephemeral read-only `media_ticket` (passed via `?ticket=` for media streams and `Sec-WebSocket-Protocol` for WebSockets).
- **FFmpeg Input Stream Indexing**: Track `input_count` separately from `inputs.len()` (which counts CLI flag strings like `-loop`, `1`, `-i`, `path`) so `-filter_complex` stream indices `[k:v]`/`[k:a]` always match FFmpeg's 0-based input indices.
- **Constant-Memory HTTP Range Streaming**: `206 Partial Content` responses must stream via `ReaderStream::new(file.take(len))` with `Content-Length: len`, never `file.read_exact(&mut vec![0u8; len])`.
- **Undo Stack Isolation for Background Metadata**: Derived background jobs (`UpdateMediaIntelligence`, proxy generation) must never push onto `undo_stack` or clear `redo_stack`.
- **Audio Analysis Without Video Decoding**: Always pass `-vn` to FFmpeg `silencedetect`, `ebur128`, and PCM peak extraction passes, and combine `silencedetect` + `ebur128` into one pass.
- **OpenRouter Tool Naming & Fallback Arrays**: OpenAI/Anthropic endpoints via OpenRouter reject dots in function names; send underscore names (`timeline_place_clip`) to OpenRouter and dot names (`timeline.place_clip`) in MCP `tools/list`, normalizing both in `execute_tool`. When sending model fallbacks, pass `models: [primary, ...fallbacks]` with `model: None`.
- **Byte-Buffered SSE UTF-8 Framing**: Always buffer raw `Vec<u8>` up to `b'\n'` before UTF-8 decoding SSE streams so multi-byte characters split across HTTP chunks are never corrupted.
- **Sequential Swarm Status Channel**: Never spawn detached `RwLock::write` tasks from an async `on_status` callback; route updates through an `mpsc` channel drained by a single sequential writer so intermediate states can never overwrite `Completed`/`Failed`.
- **Single-Parity MCP `stdio` Bridge**: Forwarding `solaris-mcp` `stdio` JSON-RPC directly to `solaris-server`'s `/mcp` Streamable HTTP endpoint guarantees 100% tool parity (`preview.capture_frame`, `preview.seek`, live `McpExternal` cursors) without duplicating REST client logic.
- **Sync `AssetStorage` in Async Contexts**: Because `AssetStorage` is a synchronous trait called from both sync tests and Tokio async handlers, `S3Storage` runs `reqwest` HTTP calls on a dedicated `std::thread::spawn` with a `current_thread` Tokio runtime rather than `block_in_place` (which panics on `#[tokio::test]` single-threaded runtimes).
- **Zero-Extra-Crate SigV4 Signing**: Reusing `ring` (`digest::SHA256`, `hmac::HMAC_SHA256`) already in `Cargo.lock` keeps `S3Storage` lightweight and audit-friendly without pulling in heavy cloud SDK dependency trees.
- **Non-Loopback Host File Read Guard**: `allow_external_media_reads` must default to `false` whenever `solaris-server` binds outside loopback so authenticated web/Docker clients cannot import arbitrary container paths.
- **FFmpeg Overlay & Alpha Export Safety**: Single-image PNG overlays require `eof_action=repeat` (or `-loop 1` + `shortest=1`) so overlays don't vanish after frame 1; alpha exports (`MovProRes4444`/`WebmAlpha`) require `:format=auto` on `overlay`, `format=rgba` before transparent padding, and preserving alpha around color grading; always drain `child.stderr` concurrently on a background thread to prevent OS pipe deadlocks.
- **Chromium `file:///` & Sandboxed GFX CSP**: Canonicalize relative HTML paths and percent-encode segments before launching headless Chromium; inject `Content-Security-Policy: default-src 'none'; style-src 'unsafe-inline'; script-src 'unsafe-inline'; img-src data:; font-src data:;` alongside bundled GSAP + base64 `@font-face` rules so offline/sandboxed motion graphics render deterministically without CDN access.
- **FFmpeg 8 `af_whisper` NDJSON Format**: FFmpeg 8's `whisper` audio filter emits newline-delimited JSONL (`start`/`end` in milliseconds) rather than a single OpenAI JSON object; always parse both formats and preserve short zero-duration words (`start == end`) with a minimal `0.05s` duration.
- **OpenRouter Model Discovery & Streaming Resilience**: Query OpenRouter `/models` with `output_modalities=all` so audio/STT models aren't filtered out; guard JSON `null` values in model metadata with `deserialize_null_default`; check for HTTP `200 OK` JSON `{"error": ...}` bodies during SSE streaming; use `connect_timeout` + `read_timeout` (not total request timeout) and cap/validate tool-call JSON arguments before dispatching tools.
- **WebGL2 3D LUT Half-Texel Addressing**: Sample 3D LUT textures using `(rgb * (u_lutSize - 1.0) + 0.5) / u_lutSize` so `0.0` and `1.0` land on exact texel centers without edge bleeding, and trigger an immediate redraw once the `.cube` LUT texture finishes uploading.
- **Monotonic UI State & WS Event Ordering**: Emit WebSocket `OpCommitted`/`ProjectReset` while holding the project write lock so revision order is strictly monotonic on the wire; guard React `activeProject`, `exportJob`, and `swarmRun` updates against stale HTTP `202` or out-of-order responses; never store API keys or auth tokens in `localStorage` (use OS Keychain via Tauri + authenticated `/api/v1/agent/credentials` / `HttpOnly` session cookies).
- **Tauri Startup Race & Native Export Downloads**: Declare `"create": false` on the main window in `tauri.conf.json`, bind and `app.manage(...)` the embedded `solaris-server` *before* calling `WebviewWindowBuilder::from_config`, trigger graceful shutdown on `RunEvent::Exit`, and provide a confined native `save_export_file` bridge for macOS WKWebView downloads.
- **Persistent CDP Chromium Rendering**: Reusing a single headless Chromium process via local Chrome DevTools Protocol (`Page.navigate` + `Runtime.evaluate` + `Page.captureScreenshot`) eliminates per-frame cold startup overhead on animated GFX/caption sequences while keeping strict offline network isolation and RAII `ChildGuard` process reaping.
- **Unquoted 2-Level FFmpeg Filter Path Escaping & FFmpeg 8/9 `-filter_complex`**: Passing unquoted 2-level escaped paths to `lut3d=file=...` and `whisper=model=...` avoids quote-nesting bugs on paths containing apostrophes, colons, or backslashes. In FFmpeg 8+/9+, `-filter_complex_script` was removed in favor of `-/filter_complex <file>`; pass `-filter_complex` inline for standard graphs (`<= 24 KiB`) and use `-/filter_complex` with fallback to `-filter_complex_script` for oversized graphs so exports work seamlessly across FFmpeg 5–9.
- **Graceful WebSocket Shutdown Token**: `axum::serve(...).with_graceful_shutdown(...)` waits for active upgraded WebSocket connections to finish before exiting; cancel a shared `CancellationToken` in `AppStateInner` during `SIGTERM`/`SIGINT` and Tauri `RunEvent::Exit` so `handle_ws`'s `tokio::select!` immediately sends a Close frame and terminates cleanly (with a 3s timeout + task abort safety net in desktop mode).
- **Tauri CSP & Sandboxed GFX Endpoint**: Keeping `script-src 'self'` on the main document while serving untrusted LLM-authored GFX HTML from `/api/v1/gfx/sandbox/{id}` (authorized via `?ticket=`/cookie, `frame-src 'self' http://127.0.0.1:* data: blob:`, and response `Content-Security-Policy: ...; sandbox allow-scripts`) isolates GFX execution in a unique opaque origin without weakening main-window CSP.
- **WebGL2 Ref Stabilization & Non-Blocking Disk Persistence**: Keep imperative WebGL2/audio/RAF callbacks reading from stable refs instead of recreating render loops on React state churn, and serialize brand/asset JSON writes behind dedicated `tokio::sync::Mutex<()>` persist locks so global `RwLock` maps are never held across disk `fsync`.
