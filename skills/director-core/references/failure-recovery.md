# Solaris Failure Recovery Guide

Use this symptom-to-fix table whenever a Solaris tool returns an error or an inspection reveals a runtime limitation.

| Symptom / Error | Root Cause | Exact Recovery Action |
| --- | --- | --- |
| `track '<id>' is locked` | Either another agent holds an agent lock or the human user locked the track in Studio. | Check `project.get` (`track.locked` / `locked_by`). If you locked it, call `project.unlock_track`. If user-locked, **do not fight the lock**—skip edits to that track and inform the user. |
| `no active video/image clip at <t>s` on `preview.capture_frame` | `preview.capture_frame` needs an active `V1` or `V2` visual clip at `time_sec` (audio-only or empty gap fails). | Inspect `project.get` to find covered `[start_sec, start_sec + duration_sec)` windows on `v1`/`v2`, or place visual clips first, then retry with a covered `time_sec`. |
| `transcript` is empty in `media.get_manifest` | Asset has not been transcribed yet, has `has_audio: false`, or Whisper/OpenRouter STT is not configured. | Call `media.transcribe(project_id, media_id)`. If transcription errors due to missing Whisper model & no OpenRouter key, tell the user clearly to configure an OpenRouter key in **AI & Keys** or install FFmpeg Whisper, and continue visual/audio editing without fake captions. |
| `captions.generate_from_transcript` places 0 clips | No placed `V1`/`A1` clips overlap transcribed word timestamps, or `media_id` has no transcript. | Verify `V1` or `A1` clips exist covering the spoken range (`source_in_sec` + `duration_sec`), ensure `media.transcribe` succeeded, then re-run `captions.generate_from_transcript`. |
| `gfx.lint_html` or `gfx.place` rejects HTML | Missing `class="clip"` / `data-start` / `data-duration`, exceeds `128 KB`, contains external URLs (`http://`, `<script src>`), or uses banned non-deterministic JS (`Date.now`, `Math.random`, `setInterval`, `requestAnimationFrame`). | Read `skill://captions-and-gfx/references/gfx-contract.md`. Strip external assets, use bundled `window.gsap` or `window.__solarisOnSeek`, re-run `gfx.lint_html`, then call `gfx.place`. |
| `gfx.place` succeeded but overlay is centered over the speaker / captions | `gfx.place` always initializes `Transform2D` to `x: 0, y: 0, scale: 1`. | Immediately follow up with `timeline.set_transform(project_id, track_id="g1", clip_id=..., y=-0.22, scale=0.9)`. |
| `color.set_grade` fails with `track_id`/`clip_id` | Either only one of `track_id`/`clip_id` was passed, or the target clip is not `ClipKind::Grade` on `fx`. | Omit both `track_id` and `clip_id` to grade the project globally (`project.active_grade`), unless `project.get` shows an existing `fx` grade clip to target. |
| `color.get_scope_stats` shows no pixel luma/waveform numbers | By design, `color.get_scope_stats` returns metadata (`active_grade`, `brand_default_lut`, `log_footage_assets`), not live pixels. | Call `preview.capture_frame` at representative shots to visually inspect exposure, contrast, and skin tones. |
| `audio.normalize_lufs` didn't fully reach `-14 LUFS` | Solaris safely clamps single-clip `gain_db` to `[-12.0, +12.0]` dB to prevent noise-floor amplification. | Do not loop `audio.normalize_lufs` endlessly; leave clamped at `+12 dB` and tell the user the source recording is very quiet (`< -26 LUFS`). |
| `media.import` rejected with external-read error | `solaris-server` is bound non-loopback or `SOLARIS_ALLOW_EXTERNAL_READS=false`, blocking arbitrary host paths. | Ask the user to upload media via Studio's **Attach Media / Add** button (multipart upload into confined workspace storage) or enable external reads explicitly for trusted local sessions. |
| `render.export` fails mentioning FFmpeg or Chromium | Local `ffmpeg`/`ffprobe` or headless Chromium is unavailable in the host environment. | Report the exact missing binary (`ffmpeg` via Homebrew/`SOLARIS_FFMPEG_PATH`, or Chromium via `SOLARIS_CHROME_PATH` for `G1`/`T1` overlays) and do not retry blindly. |
| Visual regression after a batch of edits | New grade, crop, or overlay looks worse on `preview.capture_frame`. | Call `project.undo` to roll back cleanly (transcripts, proxies, and manifests are preserved across undo), then apply a smaller targeted adjustment. |
